# كاشير محل المنظفات

برنامج كاشير وإدارة مبيعات يعمل محليًا على Windows باستخدام Electron.

## البيانات
البيانات تُحفظ محليًا داخل مجلد بيانات البرنامج على نفس الجهاز، ولا تعتمد على المتصفح أو الإنترنت.

## التشغيل
```bash
npm install
npm start
```

## بناء EXE
```bash
npm install
npm run dist
```

أو استخدم GitHub Actions من تبويب Actions.

المطور: محمد عبدالحفيظ
